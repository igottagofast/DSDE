# Data Dictionary & Variable Schema

เอกสารพจนานุกรมข้อมูล (Data Dictionary) สำหรับโครงการวิเคราะห์ทิศทางหุ้นนำเข้า-ส่งออกด้วยปัจจัยมหภาค

---

## 1. ข้อมูลหุ้น (Stock Universes)

### กลุ่มหุ้นนำเข้า (Import-Oriented Stocks)
* **คัดเลือก 8 ตัวหลัก**:
  * `PTTGC` (พีทีที โกลบอล เคมิคอล): ปิโตรเคมี นำเข้าก๊าซและน้ำมันดิบ
  * `TOP` (ไทยออยล์): โรงกลั่นน้ำมัน นำเข้าน้ำมันดิบ
  * `IRPC` (ไออาร์พีซี): โรงกลั่นและปิโตรเคมี
  * `IVL` (อินโดรามา เวนเจอร์ส): เคมีภัณฑ์ภัณฑ์ระดับโลก
  * `GPSC` (โกลบอล เพาเวอร์ ซินเนอร์ยี่): โรงไฟฟ้า นำเข้าก๊าซธรรมชาติ/ถ่านหิน
  * `EGCO` (ผลิตไฟฟ้า): โรงไฟฟ้าขนาดใหญ่
  * `RATCH` (ราช กรุ๊ป): โรงไฟฟ้า
  * `BCP` (บางจาก คอร์ปอเรชั่น): โรงกลั่นและพลังงานทดแทน
* *ตัดออก (ประวัติข้อมูลไม่ครบช่วงเวลา)*: `COM7`, `BGRIM`

### กลุ่มหุ้นส่งออก (Export-Oriented Stocks)
* **คัดเลือก 8 ตัวหลัก**:
  * `DELTA` (เดลต้า อีเลคโทรนิคส์): ชิ้นส่วนอิเล็กทรอนิกส์
  * `HANA` (ฮานา ไมโครอิเล็คโทรนิคส): เซมิคอนดักเตอร์และไมโครอิเล็กทรอนิกส์
  * `KCE` (เคซีอี อีเลคโทรนิคส์): แผงวงจรพิมพ์ (PCB) รถยนต์
  * `CPF` (เจริญโภคภัณฑ์อาหาร): เกษตรอุตสาหกรรมและอาหารแปรรูป
  * `TU` (ไทยยูเนี่ยน กรุ๊ป): อาหารทะเลแช่แข็งและบรรจุกระป๋อง
  * `STA` (ศรีตรังแอโกรอินดัสทรี): ยางพาราธรรมชาติ
  * `BDMS` (กรุงเทพดุสิตเวชการ): บริการทางการแพทย์สำหรับชาวต่างชาติ (Medical Tourism)
  * `BH` (โรงพยาบาลบำรุงราษฎร์): บริการทางการแพทย์ระดับพรีเมียมแก่ลูกค้าต่างชาติ
* *ตัดออก (ประวัติข้อมูลไม่ครบช่วงเวลา)*: `AAI`, `ITC`

## 2. ตัวแปรเป้าหมาย (Prediction Targets - Direction Classification)

พยากรณ์ทิศทางของผลตอบแทนในวันทำการถัดไป ($t+1$):
* `1` = ทิศทางราคาเป็นบวก (Positive Return / Up)
* `0` = ทิศทางราคาเป็นลบหรือเสมอตัว (Zero / Negative Return / Down)

| Target Name | Description | Target Type |
| :--- | :--- | :--- |
| `Import_Avg` | พอร์ตโฟลิโอเฉลี่ยหุ้นกลุ่มนำเข้า 8 ตัว | Portfolio Direction |
| `Export_Avg` | พอร์ตโฟลิโอเฉลี่ยหุ้นกลุ่มส่งออก 8 ตัว | Portfolio Direction |
| `BH_Pct` | หุ้นบำรุงราษฎร์ (ตัวแทนหุ้นส่งออกบริการทางการแพทย์) | Single Stock Direction |
| `BDMS_Pct` | หุ้นกรุงเทพดุสิตเวชการ (ตัวแทนหุ้นส่งออกบริการทางการแพทย์) | Single Stock Direction |
| `EGCO_Pct` | หุ้นผลิตไฟฟ้า (ตัวแทนหุ้นกลุ่มนำเข้าพลังงาน) | Single Stock Direction |
| `BCP_Pct` | หุ้นบางจาก (ตัวแทนหุ้นกลุ่มนำเข้าน้ำมันดิบ/โรงกลั่น) | Single Stock Direction |

## 3. ตัวแปรต้นมหภาคและดัชนี (Features)

### ปัจจัยมหภาคดั้งเดิม (Baseline Macro Features)
* `Brent`: ราคาน้ำมันดิบเบรนท์ (USD/Barrel)
* `WTI`: ราคาน้ำมันดิบเวสต์เท็กซัส (USD/Barrel)
* `USD_THB`: อัตราแลกเปลี่ยนเงินบาทเทียบดอลลาร์สหรัฐ (THB/USD)
* `US_10Y`: อัตราผลตอบแทนพันธบัตรรัฐบาลสหรัฐอเมริกา อายุ 10 ปี (%)
* `US_30Y`: อัตราผลตอบแทนพันธบัตรรัฐบาลสหรัฐอเมริกา อายุ 30 ปี (%)
* `BOT_Rate`: อัตราดอกเบี้ยนโยบายอ้างอิงประจำวัน ธนาคารแห่งประเทศไทย (%)
* `TH_10Y`: ผลตอบแทนพันธบัตรรัฐบาลไทย อายุ 10 ปี (%)
* `TH_20Y`: ผลตอบแทนพันธบัตรรัฐบาลไทย อายุ 20 ปี (%)

### ฟีเจอร์ทางการเงินขั้นสูง (Engineered Features)
* `Yield_Curve_Slope`: ความชันเส้นอัตราผลตอบแทนพันธบัตรไทย (`TH_20Y - TH_10Y`)
* `Volatility_to_Open`: อัตราส่วนความผันผวนระหว่างวันเทียบราคาเปิด (`(High - Low) / Open`)
* `Daily_Volatility`: ส่วนต่างราคาเปิดและปิดรายวัน (`High - Low`)
* `Relative_Return_vs_FX`: ผลตอบแทนส่วนต่างระหว่างหุ้นกับอัตราแลกเปลี่ยน
* `Relative_Strength_Ratio`: อัตราส่วนความแข็งแกร่งเชิงเปรียบเทียบ (`Export Close / Import Close`)

### ปัจจัยตลาดโลกและอัตราแลกเปลี่ยนเสริม (Phase 2 Expanded Features)
* `DXY`: US Dollar Index
* `VIX`: CBOE Volatility Index (ดัชนีความกลัวในตลาดหุ้นสหรัฐฯ)
* `SOX`: PHLX Semiconductor Index
* `SP500`: S&P 500 Index
* `SET50`: SET 50 Index (ดัชนีหุ้นไทยขนาดใหญ่ 50 ตัว)
* `CNY_THB`, `EUR_THB`, `JPY_THB`: อัตราแลกเปลี่ยนคู่เงินทางเลือก
